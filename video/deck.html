The problem

Read a CVE description → pick 8 CVSS metrics → compute the score

Analysts do this by hand for tens of thousands of CVEs a year. ThreatWeigh trains 8 independent classifiers, one per metric, and explains which words each one used.

Practically tied. ThreatWeigh − SBERT = +0.05 pp (95% CI −0.02 to +0.13). Largest gain on PR (+0.52 pp), borderline after correction.
Ablations & weights 5/10/20 all within 0.11 pp. The 11× weight fires on ≤ 1% of tokens.
Newer CVEs (train ≤ 2021, test ≥ 2023): ThreatWeigh 88.33% vs TF-IDF 87.15%, macro-F1 +4.6 pp.
Explanations are faithful (deletion-AUC 0.49 vs 0.79 random) but lexicon cues can mislead: “administrator” → PR:High.

Observed results, one seed, CPU budget — not the paper's full-scale setting (~96.2% reported). Associations, not causes.
